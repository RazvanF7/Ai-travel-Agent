Tabele principale
Tabel Câmpuri cheie Relații

ItineraryItemday, order, title, location, start_time→ Trip
Messagemessage_type (text|system|ai), content→ Group, auth_user

03

Interacțiunea Agenților AI

Trei agenți specializați cu roluri distincte, toți protejați de un rate limiter global (3 req/min, 10 req/oră per utilizator).

Pathfinder
Generează itinerariu complet din preferințele utilizatorului, cu 4 strategii de JSON parsing robust.
Gemini / Ollama Atomic DB tx
Concierge
Asistență în timp real cu SSE streaming token-by-token. Poate sugera modificări de itinerariu.
SSE stream Async
Moderator
Moderare automată a mesajelor de chat. Politică fail-open: la orice eroare, mesajul este permis.
Groq API temp=0
3.1 Pathfinder — Generare Itinerariu (US-005)
1
POST /api/ai/generate-itinerary/
Frontend trimite trip_id și preferințele utilizatorului.
2
Rate Limit check
Verificare contor per utilizator. La depășire → 429 Too Many Requests cu retry_after.
3
Fetch Trip din DB
Extrage destinație, durată, buget și monedă din PostgreSQL.
4
LLM call → parse JSON
Pathfinder Agent apelează LLM și parsează răspunsul cu 4 strategii de fallback.
5
Tranzacție atomică DB
DELETE itinerariu vechi → CREATE ItineraryItem × N → CREATE Message (type=ai).
3.2 Concierge — SSE Streaming (US-013)
1
POST /api/ai/concierge/
Frontend trimite întrebarea utilizatorului și trip_id.
2
Build context
Agent construiește contextul: informații trip, UTC time, mesaje recente.
3
SSE stream token-by-token
LLM returnează chunk-uri; fiecare token este trimis imediat ca event: token via text/event-stream.
4
event: complete
La final, dacă răspunsul conține [ITINERARY_SUGGESTION], frontend afișează butonul "Adaugă la itinerariu".
3.3 Moderator — Chat Moderation (Groq)
1
POST /api/chat/<group_id>/send/
Mesajul ajunge la Chat View înainte de a fi persistat.
2
Groq API call (temp=0)
Dacă GROQ_API_KEY este configurat, se apelează Llama 3.1 8B Instant pentru clasificare.
3
Decizie allow / block
Mesaj blocat → 403 Forbidden. Mesaj permis → Message.objects.create(). Politică fail-open la orice excepție sau JSON invalid.
